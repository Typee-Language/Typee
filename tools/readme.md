## External tools used with Typee framework
Some external tools may be used with **Typee** framework, either permanently or temporarily.  
Temporarily means: until similar tools will have been coded specifially for **Typee environment** or for **Typee language**.

For instance, such a tool that could be temporarily used is [*Notepad++*](https://notepad-plus-plus.org/) (author: [Don Ho](https://notepad-plus-plus.org/author/)), as well as Microsoft&trade; **VS Code**&trade; before a specific IDE will have been implemented for **Typee environment**.

### About Notepad++
This great free text editor has been developed by Don Ho. **Typee language** syntax coloring configuration is available for this text editor in subdirectory [`./Notepad++XML-configs/`](./Notepad++XML-configs). There, document [readme.md](./Notepad++XML-configs/readme.md) explains the how-to.

### About VS Code&trade;
It is planned as a feature that a VS Code&trade; extension will be implemented for **Typee**. Notice: planned feature does not mean planned date yet.
