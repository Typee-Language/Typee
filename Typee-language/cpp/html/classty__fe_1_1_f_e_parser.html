Detailed Description

The Front-End parser of Typee-language "T".

The external library PEGTL is used for the purpose of scanning and parsing Typee modules content according to the Typee language PEG format specification. PEGTL groups these two first steps of modern compilers into a single pass.

Notice: As a first intention, T code modules are loaded in memory space when parsed from file. This will avoid parsing very large modules and will speed-up the parsing process. Parsing from files on disks will be provided in a next release.
